# Santiago Ortiz | Video Editor & Motion Designer

Portfolio site, a single `index.html` served by GitHub Pages.

## Adding videos

Put the files in the same folder as `index.html`:

| Section | Files |
|---|---|
| Reels & Shorts | `reel-01.mp4` to `reel-07.mp4` (vertical 9:16) |
| YouTube & long-form | `yt-01.mp4` to `yt-05.mp4` (16:9) |
| Motion graphics & VFX | `motion-01.mp4` to `motion-05.mp4` |
| Hero background (optional) | `showreel.mp4` |
| About portrait | `foto.jpg` |

GitHub limits: each file under 100 MB, whole site under 1 GB. Keep clips short (5 to 15 s, 720p, H.264, `-movflags +faststart`) and use YouTube (`yt:'VIDEO_ID'` in the `WORK` block of `index.html`) for full-length videos.
